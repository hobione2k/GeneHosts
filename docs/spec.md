# 仕様

## 動作環境

* ブラウザ上でローカル動作
* 外部にファイルを送信しないこと(CSPで定義)

## 機能

### IPアドレス、ホスト名の一括出力

#### IPアドレスの指定

* IPv4アドレスのみ対応
* 開始IPは完全なIPアドレスで指定
* 終了は開始IPの末尾オクテットを置き換える値で指定
  * 例: 開始「192.168.1.10」+ 終了「20」→ 192.168.1.20
  * 例: 開始「192.168.1.10」+ 終了「2.20」→ 192.168.2.20
* 開始IP・終了は↑↓キーで±1(終了は-1/+1ボタンも可)

#### ホスト名の指定

* ホスト名のプリフィックスを指定
* ホストの末尾の開始、終了番号を指定
* ホストの番号は0埋めのため、桁数も指定可能にする
* 番号は指定桁数で0埋め(指定桁数を超える番号はそのまま出力)
* 「番号をIPアドレス末尾に合わせる」オプション
  * オン時はホスト番号をIPの第4オクテットに合わせる
  * 開始・終了番号は自動設定(編集不可)
  * 第4オクテットの範囲を超える指定はエラー

### hostsファイル向けの出力

* hostsファイルのフォーマットは`IPアドレス ホスト名`
* テキストフィールドに出力
* IPとホストの件数を自動で揃える
  * 編集中の側(IP / ホスト)の件数に合わせ、相手側の終了値を自動変更
  * 初期表示など編集中の側がない場合は大きい方に合わせる
* 入力値の変更時に自動で出力を更新
* クリープボードへのコピーボタンを設置する

### 入力値の保持

* 入力値をブラウザ(localStorage)に保存
* 次回表示時に前回の入力値を復元

## GUI

* ライト/ダークテーマの切り替えが可能
