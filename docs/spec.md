# 仕様

## 動作環境

* ブラウザ上でローカル動作
* 外部にファイルを送信しないこと(CSPで定義)

## 機能

### IPアドレス、ホスト名の一括出力

#### IPアドレスの指定

* IPv4アドレスのみ対応
* IPアドレスはプリフィックスを共通指定
* IPアドレスの開始、終了アドレスを指定

#### ホスト名の指定

* ホスト名のプリフィックスを指定
* ホストの末尾の開始、終了番号を指定
* ホストの番号は0埋めのため、桁数も指定可能にする
* 終了番号の桁数が指定桁数より長い場合は、長い方に合わせる

### hostsファイル向けの出力

* hostsファイルのフォーマットは`IPアドレス ホスト名`
* テキストフィールドに出力
* IPとホストの件数を自動で揃える
  * 編集中の側(IP / ホスト)の件数に合わせ、相手側の終了値を自動変更
  * 初期表示など編集中の側がない場合は大きい方に合わせる
* 入力値の変更時に自動で出力を更新
* クリープボードへのコピーボタンを設置する

## GUI

* ライト/ダークテーマの切り替えが可能
